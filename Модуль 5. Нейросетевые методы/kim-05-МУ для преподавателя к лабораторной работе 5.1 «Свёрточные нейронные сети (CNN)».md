### 4. Рекомендации по проведению отдельных разделов

#### 4.1. Вступительная лекция

**Ключевые темы для объяснения:**

1. **Почему обычные нейронные сети не подходят для изображений?**
   - Слишком много параметров.
   - Отсутствие инвариантности к сдвигу.
   - Потеря пространственной структуры.

2. **Как работает свёртка?**
   - Демонстрация на анимации.
   - Формула: $ (I * K)(i,j) = \sum_{m}\sum_{n} I(i+m, j+n) \cdot K(m,n) $.
   - Понятие ядра (фильтра), карты признаков.

3. **ReLU и другие функции активации.**
   - Преимущества ReLU перед сигмоидой.
   - Проблема «умирающих» нейронов.

4. **Подвыборка (Pooling).**
   - Max pooling vs Average pooling.
   - Уменьшение размерности, увеличение receptive field.

5. **Регуляризация.**
   - Dropout: случайное отключение нейронов.
   - Batch Normalization: нормализация активаций.
   - L1/L2 регуляризация.

6. **PyTorch essentials:**
   - `nn.Module` — базовый класс для всех моделей.
   - `forward()` — определение прямого прохода.
   - `DataLoader` — загрузка данных батчами.
   - `optimizer.zero_grad()` → `loss.backward()` → `optimizer.step()`.

#### 4.2. Разработка моделей

**Простая модель (базовый уровень):**
```python
class SimpleCNN(nn.Module):
    def __init__(self, num_classes=10):
        super(SimpleCNN, self).__init__()
        self.conv1 = nn.Conv2d(3, 32, kernel_size=3, padding=1)
        self.conv2 = nn.Conv2d(32, 64, kernel_size=3, padding=1)
        self.conv3 = nn.Conv2d(64, 64, kernel_size=3, padding=1)
        self.pool = nn.MaxPool2d(2, 2)
        self.fc1 = nn.Linear(64 * 4 * 4, 64)
        self.fc2 = nn.Linear(64, num_classes)
        self.dropout = nn.Dropout(0.5)

    def forward(self, x):
        x = self.pool(F.relu(self.conv1(x)))
        x = self.pool(F.relu(self.conv2(x)))
        x = self.pool(F.relu(self.conv3(x)))
        x = x.view(-1, 64 * 4 * 4)
        x = F.relu(self.fc1(x))
        x = self.dropout(x)
        x = self.fc2(x)
        return x
```

**Глубокая модель с регуляризацией:**
```python
class DeepCNN(nn.Module):
    def __init__(self, num_classes=10):
        super(DeepCNN, self).__init__()
        # Conv block 1
        self.conv1 = nn.Conv2d(3, 32, kernel_size=3, padding=1)
        self.bn1 = nn.BatchNorm2d(32)
        self.conv2 = nn.Conv2d(32, 32, kernel_size=3, padding=1)
        self.bn2 = nn.BatchNorm2d(32)
        self.pool1 = nn.MaxPool2d(2, 2)
        
        # Conv block 2
        self.conv3 = nn.Conv2d(32, 64, kernel_size=3, padding=1)
        self.bn3 = nn.BatchNorm2d(64)
        self.conv4 = nn.Conv2d(64, 64, kernel_size=3, padding=1)
        self.bn4 = nn.BatchNorm2d(64)
        self.pool2 = nn.MaxPool2d(2, 2)
        
        # Conv block 3
        self.conv5 = nn.Conv2d(64, 128, kernel_size=3, padding=1)
        self.bn5 = nn.BatchNorm2d(128)
        self.conv6 = nn.Conv2d(128, 128, kernel_size=3, padding=1)
        self.bn6 = nn.BatchNorm2d(128)
        self.pool3 = nn.MaxPool2d(2, 2)
        
        # FC layers
        self.fc1 = nn.Linear(128 * 4 * 4, 256)
        self.dropout1 = nn.Dropout(0.5)
        self.fc2 = nn.Linear(256, 128)
        self.dropout2 = nn.Dropout(0.3)
        self.fc3 = nn.Linear(128, num_classes)

    def forward(self, x):
        x = F.relu(self.bn1(self.conv1(x)))
        x = F.relu(self.bn2(self.conv2(x)))
        x = self.pool1(x)
        x = F.relu(self.bn3(self.conv3(x)))
        x = F.relu(self.bn4(self.conv4(x)))
        x = self.pool2(x)
        x = F.relu(self.bn5(self.conv5(x)))
        x = F.relu(self.bn6(self.conv6(x)))
        x = self.pool3(x)
        x = x.view(-1, 128 * 4 * 4)
        x = F.relu(self.fc1(x))
        x = self.dropout1(x)
        x = F.relu(self.fc2(x))
        x = self.dropout2(x)
        x = self.fc3(x)
        return x
```

#### 4.3. Обучение и мониторинг

**Структура обучающего цикла в PyTorch:**
```python
def train_epoch(model, dataloader, criterion, optimizer, device):
    model.train()
    running_loss = 0.0
    correct = 0
    total = 0
    
    for inputs, labels in dataloader:
        inputs, labels = inputs.to(device), labels.to(device)
        
        optimizer.zero_grad()
        outputs = model(inputs)
        loss = criterion(outputs, labels)
        loss.backward()
        optimizer.step()
        
        running_loss += loss.item() * inputs.size(0)
        _, predicted = outputs.max(1)
        total += labels.size(0)
        correct += predicted.eq(labels).sum().item()
    
    return running_loss / len(dataloader.dataset), 100. * correct / total
```

**Важные моменты для объяснения:**
- `model.train()` и `model.eval()` — переключение режимов (важно для Dropout и BatchNorm).
- `optimizer.zero_grad()` — обнуление градиентов перед каждым шагом.
- `loss.backward()` — вычисление градиентов.
- `optimizer.step()` — обновление весов.

**Сохранение модели:**
```python
torch.save(model.state_dict(), 'best_model.pth')
```

**Мониторинг обучения:** Используйте планировщики скорости обучения из `torch.optim.lr_scheduler`.

**Как интерпретировать графики:**
- Training loss ↓ и Validation loss ↓ — хорошее обучение.
- Training loss ↓, Validation loss ↑ — переобучение.
- Training loss ↓, Validation loss стабильна — возможно, модель слишком простая (underfitting).

**Типичные ошибки:**
- Забывают переключать режимы `model.train()`/`model.eval()`.
- Не переносят данные на `device` (CPU/GPU).
- Слишком большая скорость обучения — loss не сходится.
- Слишком маленькая — обучение слишком медленное.
- Отсутствие нормализации данных — градиенты взрываются.

#### 4.4. Аугментация данных

**В PyTorch аугментация реализуется через `transforms.Compose`:**

```python
train_transform = transforms.Compose([
    transforms.RandomHorizontalFlip(),
    transforms.RandomCrop(32, padding=4),
    transforms.ToTensor(),
    transforms.Normalize((0.4914, 0.4822, 0.4465), (0.2023, 0.1994, 0.2010))
])
```

**Обоснование:** Аугментация увеличивает эффективный размер выборки и делает модель устойчивее к вариациям.

**Параметры для обсуждения:**
- `RandomHorizontalFlip`: допустимо, если объекты не имеют строгой ориентации.
- `RandomCrop`: сдвиги до 20% (padding=4 для CIFAR-10).
- `RandomRotation`: поворот до 20°.
- `ColorJitter`: изменение яркости, контрастности.

**Важно:** Аугментация применяется только к обучающей выборке, не к валидационной и тестовой.

#### 4.6. Использование предобученных моделей

**Transfer Learning** — мощный подход для задач с ограниченными данными.

**В PyTorch это реализуется через `torchvision.models`:**

```python
import torchvision.models as models

class TransferLearningCNN(nn.Module):
    def __init__(self, num_classes=10):
        super(TransferLearningCNN, self).__init__()
        self.backbone = models.resnet18(weights='IMAGENET1K_V1')
        
        # Заморозка весов
        for param in self.backbone.parameters():
            param.requires_grad = False
        
        # Замена последнего слоя
        num_features = self.backbone.fc.in_features
        self.backbone.fc = nn.Sequential(
            nn.Linear(num_features, 256),
            nn.ReLU(),
            nn.Dropout(0.5),
            nn.Linear(256, num_classes)
        )

    def forward(self, x):
        return self.backbone(x)
```

**Архитектуры для обсуждения:**
- ResNet — с skip-connections, решает проблему затухающих градиентов.
- VGG16/19 — простая, но тяжёлая.
- EfficientNet — оптимальное соотношение скорость/точность.

### 5. Типичные ошибки и способы их предотвращения

| Ошибка | Причина | Решение |
|--------|---------|---------|
| Модель не обучается (loss не падает) | Неправильная нормализация данных | Использовать `transforms.Normalize` с правильными mean/std |
| Loss становится NaN | Слишком большая скорость обучения | Уменьшить learning_rate (например, 0.001 → 0.0001) |
| Быстрое переобучение | Мало данных, нет регуляризации | Добавить Dropout, аугментацию |
| Медленное обучение | Нет BatchNormalization | Добавить `nn.BatchNorm2d` после свёрточных слоёв |
| Неправильные размеры тензоров | Ошибка в `view()` | Проверить размеры после свёрток и pooling |
| Точность на валидации ниже случайной | Перепутаны метки или неправильная функция потерь | Проверить классы и использовать `nn.CrossEntropyLoss` |
| Не хватает памяти GPU | Слишком большой батч | Уменьшить batch_size (например, 64 → 32) |
| Модель не улучшается | Слишком глубокая для данных | Упростить архитектуру |
| CUDA error: out of memory | Слишком много данных в памяти | Уменьшить batch_size или использовать `pin_memory=False` |
| Забыли переключить режим | `model.eval()` не вызван перед валидацией | Всегда вызывать `model.eval()` в validate и `model.train()` в train |

### 8. Контрольные вопросы для защиты (с ответами для преподавателя)

1. **Что такое операция свёртки и чем она отличается от полносвязного слоя в PyTorch?**  
   *Ответ:* Свёртка (`nn.Conv2d`) использует локальные связи и общие веса (ядра), что значительно уменьшает количество параметров и обеспечивает инвариантность к сдвигу. Полносвязный слой (`nn.Linear`) соединяет каждый нейрон со всеми нейронами предыдущего слоя.

2. **Почему ReLU лучше сигмоиды в скрытых слоях CNN?**  
   *Ответ:* ReLU (`nn.ReLU`) не насыщается, производная равна 1 для положительных значений, что решает проблему затухающих градиентов. Также ReLU быстрее вычисляется.

3. **Что такое Max Pooling и зачем он нужен в PyTorch?**  
   *Ответ:* `nn.MaxPool2d` выбирает максимальное значение в окне. Он уменьшает пространственную размерность, увеличивает receptive field, делает модель устойчивее к малым смещениям и уменьшает количество параметров.

4. **Как работает Dropout в PyTorch?**  
   *Ответ:* `nn.Dropout` случайно «выключает» нейроны во время обучения (в `model.train()` режиме), что предотвращает коадаптацию нейронов и заставляет модель изучать более устойчивые признаки. В `model.eval()` режиме Dropout не активен.

5. **Что такое Batch Normalization в PyTorch?**  
   *Ответ:* `nn.BatchNorm2d` нормализует активации внутри батча, центрируя и масштабируя их. Это ускоряет обучение, позволяет использовать бóльшие скорости обучения и действует как регуляризатор.

6. **Как выбрать оптимальную архитектуру CNN для конкретной задачи?**  
   *Ответ:* Исходить из сложности данных (размер изображения, количество классов). Начинать с простой модели, постепенно усложнять. Использовать transfer learning при недостатке данных.

7. **Что такое аугментация данных и как она реализуется в PyTorch?**  
   *Ответ:* Аугментация — преобразование изображений (повороты, сдвиги, отражения), увеличивающее эффективный размер выборки. В PyTorch реализуется через `torchvision.transforms`.

8. **Как интерпретировать матрицу ошибок?**  
   *Ответ:* Матрица показывает, какие классы модель путает. Анализ позволяет понять слабые места модели и, возможно, добавить больше данных для проблемных классов.

9. **Что такое Transfer Learning в PyTorch?**  
   *Ответ:* Использование предобученной модели из `torchvision.models` для новой задачи. Позволяет достичь хороших результатов с малым количеством данных.

10. **Как влияет размер батча на обучение в PyTorch?**  
    *Ответ:* Малый батч даёт более шумные градиенты (лучше обобщение, но медленнее сходимость). Большой батч даёт стабильные градиенты (быстрее сходимость, но хуже обобщение и больше памяти).

11. **В чём отличие `nn.CrossEntropyLoss` от комбинации `nn.LogSoftmax` + `nn.NLLLoss`?**  
    *Ответ:* `nn.CrossEntropyLoss` объединяет LogSoftmax и NLLLoss в один слой, что упрощает код и более численно стабильно.

12. **Зачем нужен вызов `optimizer.zero_grad()` в PyTorch?**  
    *Ответ:* Чтобы обнулить накопленные градиенты перед новым шагом. Без этого градиенты будут суммироваться с предыдущего шага.

13. **Что делает `model.eval()` и зачем он нужен?**  
    *Ответ:* Переключает модель в режим оценки: отключает Dropout и использует скользящие средние в BatchNorm. Обязательно вызывать перед валидацией.

14. **Как сохранить и загрузить модель в PyTorch?**  
    *Ответ:* `torch.save(model.state_dict(), 'model.pth')` для сохранения весов и `model.load_state_dict(torch.load('model.pth'))` для загрузки.

15. **Что такое `DataLoader` в PyTorch и зачем он нужен?**  
    *Ответ:* `DataLoader` загружает данные батчами, перемешивает (`shuffle=True`), может использовать несколько потоков (`num_workers`) для ускорения.

### 11. Дополнительные материалы для преподавателя

#### 11.1. Пример полного обучающего скрипта на PyTorch

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import torch.optim as optim
from torch.utils.data import DataLoader
from torchvision import datasets, transforms
import matplotlib.pyplot as plt

# Настройка устройства
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
print(f"Используется устройство: {device}")

# Трансформации
transform = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.5,), (0.5,))
])

# Загрузка данных
train_dataset = datasets.MNIST('./data', train=True, download=True, transform=transform)
test_dataset = datasets.MNIST('./data', train=False, download=True, transform=transform)

train_loader = DataLoader(train_dataset, batch_size=64, shuffle=True, num_workers=2)
test_loader = DataLoader(test_dataset, batch_size=64, shuffle=False, num_workers=2)

# Модель
class SimpleCNN(nn.Module):
    def __init__(self, num_classes=10):
        super(SimpleCNN, self).__init__()
        self.conv1 = nn.Conv2d(1, 32, kernel_size=3, padding=1)
        self.conv2 = nn.Conv2d(32, 64, kernel_size=3, padding=1)
        self.pool = nn.MaxPool2d(2, 2)
        self.fc1 = nn.Linear(64 * 7 * 7, 128)
        self.fc2 = nn.Linear(128, num_classes)
        self.dropout = nn.Dropout(0.5)

    def forward(self, x):
        x = self.pool(F.relu(self.conv1(x)))
        x = self.pool(F.relu(self.conv2(x)))
        x = x.view(-1, 64 * 7 * 7)
        x = F.relu(self.fc1(x))
        x = self.dropout(x)
        x = self.fc2(x)
        return x

# Функции обучения
def train_epoch(model, dataloader, criterion, optimizer, device):
    model.train()
    running_loss = 0.0
    correct = 0
    total = 0
    
    for inputs, labels in dataloader:
        inputs, labels = inputs.to(device), labels.to(device)
        
        optimizer.zero_grad()
        outputs = model(inputs)
        loss = criterion(outputs, labels)
        loss.backward()
        optimizer.step()
        
        running_loss += loss.item() * inputs.size(0)
        _, predicted = outputs.max(1)
        total += labels.size(0)
        correct += predicted.eq(labels).sum().item()
    
    return running_loss / len(dataloader.dataset), 100. * correct / total

def validate(model, dataloader, criterion, device):
    model.eval()
    running_loss = 0.0
    correct = 0
    total = 0
    
    with torch.no_grad():
        for inputs, labels in dataloader:
            inputs, labels = inputs.to(device), labels.to(device)
            outputs = model(inputs)
            loss = criterion(outputs, labels)
            
            running_loss += loss.item() * inputs.size(0)
            _, predicted = outputs.max(1)
            total += labels.size(0)
            correct += predicted.eq(labels).sum().item()
    
    return running_loss / len(dataloader.dataset), 100. * correct / total

# Обучение
model = SimpleCNN(num_classes=10).to(device)
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)

num_epochs = 10
train_losses, val_losses = [], []
train_accs, val_accs = [], []

for epoch in range(num_epochs):
    train_loss, train_acc = train_epoch(model, train_loader, criterion, optimizer, device)
    val_loss, val_acc = validate(model, test_loader, criterion, device)
    
    train_losses.append(train_loss)
    val_losses.append(val_loss)
    train_accs.append(train_acc)
    val_accs.append(val_acc)
    
    print(f'Epoch {epoch+1}/{num_epochs}')
    print(f'Train Loss: {train_loss:.4f}, Train Acc: {train_acc:.2f}%')
    print(f'Val Loss: {val_loss:.4f}, Val Acc: {val_acc:.2f}%')
    print('-' * 40)

print('Обучение завершено!')

# Сохранение модели
torch.save(model.state_dict(), 'mnist_cnn.pth')
```
