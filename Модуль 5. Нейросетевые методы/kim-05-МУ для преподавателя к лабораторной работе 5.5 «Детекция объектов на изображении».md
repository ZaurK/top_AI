### 4. Рекомендации по проведению отдельных разделов

#### 4.1. Вступительная лекция

**Ключевые темы для объяснения:**

1. **Задача детекции:**
   - Что такое детекция объектов? (локализация + классификация)
   - Отличие от классификации (всё изображение → один класс) и сегментации (попиксельная классификация).
   - Реальные применения: автономное вождение, медицинская диагностика, безопасность.

2. **Bounding boxes:**
   - Форматы: (x1, y1, x2, y2) — углы прямоугольника.
   - (cx, cy, w, h) — центр, ширина, высота.
   - Нормализованные vs абсолютные координаты.

3. **Архитектуры детекторов:**
   - **Faster R-CNN:** двухэтапный подход (RPN + классификатор).
   - **SSD:** одноэтапный, многомасштабный.
   - **YOLO:** одноэтапный, разбиение на сетку.

4. **Non-Maximum Suppression (NMS):**
   - Зачем нужна (удаление дублей).
   - Как работает (сортировка по уверенности, удаление перекрывающихся).

5. **Метрики:**
   - **IoU:** отношение пересечения к объединению.
   - **AP:** площадь под Precision-Recall кривой.
   - **mAP:** среднее AP по всем классам.

6. **PyTorch для детекции:**
   - `torchvision.models.detection` — готовые модели.
   - Структура вывода модели: `{'boxes': ..., 'labels': ..., 'scores': ...}`.

**Визуальный материал:**
- Схемы архитектур детекторов.
- Анимация работы NMS.
- Примеры bounding boxes с разными IoU.
- Таблица сравнения архитектур.

#### 4.2. Создание класса Dataset

**Ключевые моменты для объяснения:**

1. **Структура Dataset для детекции:**
   - Отличается от классификации: возвращает (image, target).
   - `target` — словарь с ключами 'boxes' и 'labels'.
   - `boxes` — тензор формы (N, 4).
   - `labels` — тензор формы (N,).

2. **Важность правильного формата:**
   - `boxes` должны быть `float32`.
   - `labels` должны быть `int64`.
   - Координаты должны быть в абсолютных значениях (не нормализованных).

3. **Трансформации:**
   - Для детекции трансформации сложнее: нужно синхронно применять их к изображению и к координатам.
   - Рекомендуется использовать готовые трансформации из `torchvision.transforms.v2`.

**Типичные ошибки:**
- Неправильный формат координат (путают x1,y1,x2,y2 с cx,cy,w,h).
- Неправильный тип данных (float вместо int для labels).
- Несоответствие размеров boxes и labels.

#### 4.5. Анализ параметров детекции

**Ключевые моменты:**

1. **Порог уверенности (confidence threshold):**
   - Высокий порог → меньше ложных срабатываний, но могут быть пропуски.
   - Низкий порог → больше объектов, но много ложных срабатываний.

2. **Порог NMS (iou threshold):**
   - Высокий порог → больше дублей (перекрывающихся框).
   - Низкий порог → меньше дублей, но могут быть удалены пересекающиеся объекты.

3. **Практический эксперимент:**
   - Протестировать разные значения `confidence_threshold` на одном изображении.
   - Визуализировать результаты.

### 5. Типичные ошибки и способы их предотвращения

| Ошибка | Причина | Решение |
|--------|---------|---------|
| Неправильные координаты box'ов | Путаница в форматах (x1,y1,x2,y2 vs cx,cy,w,h) | Чётко объяснить форматы и использовать правильные функции |
| Слишком много ложных срабатываний | Низкий confidence threshold | Увеличить порог уверенности |
| Пропуск объектов | Высокий confidence threshold | Уменьшить порог уверенности или улучшить модель |
| Дублирующиеся框 | Высокий iou threshold в NMS | Уменьшить iou threshold |
| CUDA out of memory | Слишком большой batch_size | Уменьшить batch_size или использовать меньшую модель |
| Модель не видит объекты | Неправильная нормализация | Проверить предобработку изображений |
| Неправильные метки | Ошибка в индексах классов | Проверить соответствие классов в датасете и модели |
| Медленное обучение | Большой датасет без GPU | Использовать GPU или уменьшить датасет |

### 8. Контрольные вопросы для защиты (с ответами для преподавателя)

1. **В чём отличие детекции объектов от классификации изображений?**  
   *Ответ:* Классификация определяет один класс для всего изображения. Детекция определяет наличие и местоположение (bounding box) для каждого объекта на изображении.

2. **Что такое bounding box и как он задаётся в PyTorch?**  
   *Ответ:* Bounding box — прямоугольник, ограничивающий объект. В PyTorch задаётся как тензор формы (N, 4) в формате (x1, y1, x2, y2).

3. **Как работает архитектура Faster R-CNN в torchvision?**  
   *Ответ:* Двухэтапная архитектура: Region Proposal Network предлагает регионы, затем классификатор определяет класс и уточняет координаты. Реализована в `torchvision.models.detection.fasterrcnn_resnet50_fpn`.

4. **В чём отличие одноэтапных детекторов от двухэтапных?**  
   *Ответ:* Одноэтапные (YOLO, SSD) предсказывают классы и координаты за один проход — быстрее, но чуть менее точны. Двухэтапные (Faster R-CNN) сначала предлагают регионы, затем классифицируют — точнее, но медленнее.

5. **Что такое Non-Maximum Suppression (NMS) и зачем она нужна?**  
   *Ответ:* NMS удаляет дублирующиеся框, оставляя только один с максимальной уверенностью для каждого объекта. Необходима, так как детекторы часто выдают несколько框 для одного объекта.

6. **Как вычисляется метрика IoU?**  
   *Ответ:* IoU = площадь пересечения / площадь объединения двух bounding boxes. Значения от 0 до 1, где 1 — полное совпадение.

7. **Что означает показатель mAP?**  
   *Ответ:* Mean Average Precision — среднее значение AP (площадь под Precision-Recall кривой) по всем классам. Основная метрика для оценки детекторов.

8. **Как выбрать оптимальные параметры confidence threshold и IoU threshold?**  
   *Ответ:* Через экспериментальную настройку. Высокий confidence → меньше ложных срабатываний, но возможны пропуски. Низкий iou threshold → меньше дублей, но могут быть удалены пересекающиеся объекты. Оптимум зависит от задачи.

9. **В чём преимущества и недостатки YOLO и Faster R-CNN?**  
   *Ответ:* YOLO: очень быстрый, простой в использовании, но чуть менее точный. Faster R-CNN: очень точный, но медленный и сложнее в настройке.

10. **Как адаптировать предобученную модель для детекции новых классов в PyTorch?**  
    *Ответ:* Заменить голову классификатора: `model.roi_heads.box_predictor = FastRCNNPredictor(in_features, num_classes)`. Затем дообучить на новом датасете.

11. **Как работает `torchvision.models.detection.fasterrcnn_resnet50_fpn`?**  
    *Ответ:* Комбинирует ResNet50 как бэкбон (извлечение признаков) и Feature Pyramid Network (многомасштабное представление) для улучшения детекции объектов разного размера.

12. **Как создать кастомный датасет для детекции в PyTorch?**  
    *Ответ:* Создать класс-наследник `torch.utils.data.Dataset` с методами `__len__` и `__getitem__`, который возвращает `(image, target)`, где `target` — словарь с 'boxes' и 'labels'.

13. **Как работает YOLO?**  
    *Ответ:* Разбивает изображение на сетку S×S, каждая ячейка предсказывает B bounding boxes и вероятности классов. Использует единую свёрточную сеть для предсказания всех параметров.

14. **Что такое anchor boxes и зачем они нужны?**  
    *Ответ:* Заранее заданные прямоугольники разных размеров и пропорций. Детектор предсказывает смещения относительно них, что упрощает обучение.

15. **Как интерпретировать Precision-Recall кривую?**  
    *Ответ:* Показывает баланс между точностью и полнотой при разных порогах уверенности. Площадь под кривой — AP (Average Precision).

### 9. Методические рекомендации по преподаванию сложных тем

#### 9.1. Объяснение Non-Maximum Suppression (NMS)

**Аналогия:** Представьте, что вы ищете свою книгу в комнате. Несколько человек показывают на разные места, но вы выбираете самого уверенного и игнорируете остальных, если они указывают на ту же область.

**Демонстрация:** Покажите пример с несколькими框, которые перекрываются, и как NMS оставляет только один.

### 11. Дополнительные материалы для преподавателя

#### 11.1. Пример полного скрипта детекции

```python
import torch
import torchvision
from torchvision import transforms
from torchvision.models.detection import fasterrcnn_resnet50_fpn
from PIL import Image
import cv2
import numpy as np
import matplotlib.pyplot as plt

# Настройка устройства
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')

# Классы COCO
COCO_CLASSES = ['__background__', 'person', 'bicycle', 'car', 'motorcycle', 'airplane',
                'bus', 'train', 'truck', 'boat', 'traffic light', 'fire hydrant']

def detect_objects(image_path, model, confidence_threshold=0.5):
    """Детекция объектов на изображении"""
    # Загрузка и предобработка
    image = Image.open(image_path).convert('RGB')
    transform = transforms.ToTensor()
    image_tensor = transform(image).unsqueeze(0).to(device)
    
    # Инференс
    model.eval()
    with torch.no_grad():
        predictions = model(image_tensor)
    
    # Обработка результатов
    boxes = predictions[0]['boxes'].cpu().numpy()
    scores = predictions[0]['scores'].cpu().numpy()
    labels = predictions[0]['labels'].cpu().numpy()
    
    # Фильтрация
    mask = scores >= confidence_threshold
    boxes = boxes[mask].astype(int)
    scores = scores[mask]
    labels = labels[mask]
    
    return boxes, labels, scores

def visualize_results(image_path, boxes, labels, scores):
    """Визуализация результатов"""
    image = cv2.imread(image_path)
    image = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)
    
    colors = np.random.randint(0, 255, (len(set(labels)), 3))
    label_to_color = {label: colors[i] for i, label in enumerate(set(labels))}
    
    for box, label, score in zip(boxes, labels, scores):
        x1, y1, x2, y2 = box
        color = label_to_color[label]
        cv2.rectangle(image, (x1, y1), (x2, y2), color.tolist(), 2)
        cv2.putText(image, f'{COCO_CLASSES[int(label)]}: {score:.2f}',
                   (x1, y1-5), cv2.FONT_HERSHEY_SIMPLEX, 0.5, color.tolist(), 2)
    
    plt.figure(figsize=(12, 8))
    plt.imshow(image)
    plt.axis('off')
    plt.show()

# Основной процесс
if __name__ == "__main__":
    # Загрузка модели
    model = fasterrcnn_resnet50_fpn(pretrained=True).to(device)
    
    # Детекция
    image_path = 'test_image.jpg'
    boxes, labels, scores = detect_objects(image_path, model, confidence_threshold=0.5)
    
    # Визуализация
    visualize_results(image_path, boxes, labels, scores)
    
    print(f"Найдено объектов: {len(boxes)}")
    for i, (label, score) in enumerate(zip(labels, scores)):
        print(f"{i+1}. {COCO_CLASSES[int(label)]}: {score:.3f}")
```
