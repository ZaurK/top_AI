**Ключевые темы для объяснения:**

2. **Архитектура U-Net:**
   - **Encoder (сжатие):** свёрточные слои + max pooling → уменьшение размерности, захват контекста.
   - **Decoder (расширение):** транспонированные свёртки → восстановление размерности.
   - **Skip-connections:** передача детальной информации с encoder на decoder.
   - Почему это работает: сохраняется и глобальный контекст, и локальные детали.

3. **Транспонированная свёртка (`nn.ConvTranspose2d`):**
   - Как работает (увеличение размерности).
   - Проблема «шахматного» артефакта и как её избежать (интерполяция + свёртка).

4. **Функции потерь для сегментации:**
   - `CrossEntropyLoss` — стандартный выбор.
   - `Dice Loss` — лучше для несбалансированных классов.
   - Комбинированные функции потерь.

5. **Метрики качества:**
   - **IoU (Intersection over Union):** отношение пересечения к объединению.
   - **mIoU:** среднее IoU по всем классам.
   - **Pixel Accuracy:** доля правильно классифицированных пикселей.
   - Обсудить, почему mIoU лучше характеризует качество, чем Pixel Accuracy (особенно при дисбалансе классов).

#### 4.3. Реализация U-Net

**Ключевые моменты для объяснения:**

1. **DoubleConv:**
   - Два свёрточных слоя с BatchNorm и ReLU.
   - Почему два слоя? Увеличивает репрезентативную способность.

2. **Encoder:**
   - Список блоков DoubleConv.
   - После каждого блока — MaxPool2d.

3. **Decoder:**
   - `ConvTranspose2d` для upsampling.
   - Конкатенация (`torch.cat`) с skip-connection.
   - DoubleConv после конкатенации.

4. **Skip-connections:**
   - Как обеспечивается передача детальной информации.
   - Почему размеры должны совпадать (или требуется обрезка).

5. **Функция обрезки:**
   - Если размеры не совпадают (при нечётных размерах), нужно обрезать.

#### 4.4. Обучение и мониторинг

**Структура обучающего цикла:**

```python
def train_epoch(model, dataloader, criterion, optimizer, device):
    model.train()
    for images, masks in dataloader:
        images, masks = images.to(device), masks.to(device)
        optimizer.zero_grad()
        outputs = model(images)
        loss = criterion(outputs, masks)
        loss.backward()
        optimizer.step()
```

**Важные моменты для объяснения:**
- `model.train()` / `model.eval()` — режимы для Dropout и BatchNorm.
- `loss.backward()` — вычисление градиентов.
- `optimizer.step()` — обновление весов.

**Мониторинг:**
- Отслеживать train loss, val loss, val accuracy, val mIoU.
- Использовать `scheduler` для адаптивной скорости обучения.

**Типичные ошибки:**
- Забывают переключать режимы `model.train()`/`model.eval()`.
- Не переносят данные на `device` (GPU).
- Слишком большой batch_size → не хватает памяти.

#### 4.5. Вычисление метрик

**Объяснение метрик:**

1. **IoU (Intersection over Union):**
   $$
   IoU = \frac{TP}{TP + FP + FN}
   $$
   - TP: пиксели, правильно предсказанные как класс.
   - FP: пиксели, ошибочно предсказанные как класс.
   - FN: пиксели класса, не предсказанные как класс.

2. **mIoU:**
   - Среднее IoU по всем классам.
   - Более информативно, чем Pixel Accuracy при дисбалансе классов.

3. **Pixel Accuracy:**
   $$
   PA = \frac{TP + TN}{TP + TN + FP + FN}
   $$

**Обсуждение:** Почему mIoU лучше, чем Pixel Accuracy? (Пример: если 90% пикселей — фон, то модель может предсказывать только фон и иметь 90% точности, но mIoU будет низким).

### 5. Типичные ошибки и способы их предотвращения

| Ошибка | Причина | Решение |
|--------|---------|---------|
| Маски имеют значения 0–255 | Загрузка в неправильном формате | Использовать `cv2.IMREAD_GRAYSCALE` |
| Неправильные размеры при конкатенации | Несовпадение размеров skip-connection | Использовать обрезку или `padding='same'` |
| Потери не уменьшаются | Неправильный формат масок (float вместо long) | Преобразовать в `torch.long()` |
| Границы объектов размыты | Недостаточно информации от skip-connections | Увеличить количество слоёв или использовать более глубокий encoder |
| Модель предсказывает только фон | Дисбаланс классов | Добавить веса классов или использовать Dice Loss |
| Не хватает памяти GPU | Слишком большой batch_size или большое разрешение | Уменьшить batch_size или разрешение |
| mIoU не вычисляется | Деление на ноль | Добавить `1e-8` в знаменатель |
| Неправильная нормализация | Разные mean/std для изображений | Использовать стандартные значения для ImageNet |
| Аугментация нарушает соответствие | Разные трансформации для image и mask | Использовать синхронные трансформации |

### 8. Контрольные вопросы для защиты (с ответами для преподавателя)

1. **В чём отличие семантической сегментации от инстансной?**  
   *Ответ:* Семантическая классифицирует каждый пиксель по классу (например, все автомобили — один класс). Инстансная выделяет отдельные объекты (каждый автомобиль — отдельный экземпляр). Паноптическая объединяет оба подхода.

2. **Какую роль играют skip-connections в архитектуре U-Net?**  
   *Ответ:* Передают детальную информацию с encoder на decoder, позволяя восстановить точные границы объектов. Без них модель теряет пространственную информацию.

3. **Что такое транспонированная свёртка (`nn.ConvTranspose2d`) и для чего она используется?**  
   *Ответ:* Операция, увеличивающая пространственную размерность (upsampling). Используется в decoder для восстановления размера карт признаков до исходного.

4. **В чём отличие Atrous Convolution от обычной свёртки?**  
   *Ответ:* Atrous (дырчатая) свёртка имеет шаг (dilation), увеличивающий receptive field без потери разрешения. Используется в DeepLab для захвата контекста на разных масштабах.

5. **Как вычисляется метрика IoU?**  
   *Ответ:* \( IoU = \frac{TP}{TP+FP+FN} \) — отношение пересечения к объединению предсказанных и истинных пикселей класса.

6. **Почему маски нужно изменять с `interpolation=INTER_NEAREST`?**  
   *Ответ:* Чтобы не создавать промежуточных значений, не являющихся классами. Билинейная интерполяция создаёт дробные значения.

7. **Какие проблемы возникают при обучении моделей сегментации?**  
   *Ответ:* Дисбаланс классов (фон преобладает), ограничения по памяти GPU, необходимость большого количества размеченных данных, сложность детализации границ.

8. **Как выбрать количество классов для сегментации?**  
   *Ответ:* Исходить из задачи. В Oxford Pets — 3 класса (фон, кошка, собака). В Cityscapes — 19+ классов. Количество классов определяется аннотациями датасета.

9. **В чём отличие `nn.CrossEntropyLoss` от `nn.BCEWithLogitsLoss` для сегментации?**  
   *Ответ:* `CrossEntropyLoss` используется для многоклассовой сегментации (маска с индексами классов). `BCEWithLogitsLoss` — для бинарной сегментации (каждый класс предсказывается отдельно).

10. **Как аугментация данных влияет на качество сегментации?**  
    *Ответ:* Увеличивает эффективный размер выборки, делает модель устойчивее к вариациям (повороты, сдвиги, изменения освещения), снижает переобучение.

11. **Почему в U-Net используется `BatchNorm2d`?**  
    *Ответ:* Ускоряет обучение, позволяет использовать большие скорости обучения, нормализует активации, работает как регуляризатор.

12. **Как можно улучшить сегментацию мелких объектов?**  
    *Ответ:* Увеличить разрешение входных изображений, добавить больше skip-connections, использовать multi-scale подходы (например, ASPP в DeepLab).

### 9. Методические рекомендации по преподаванию сложных тем

#### 9.1. Объяснение U-Net

**Аналогия:** Представьте, что вы рассматриваете фотографию на разных масштабах. Сначала вы видите общую картину (encoder), затем приближаетесь к деталям (decoder), но при этом помните, что вы видели на каждом масштабе (skip-connections).

**Демонстрация:** Нарисуйте схему U-Net на доске, показывая поток данных и размеры на каждом этапе.

#### 9.2. Объяснение транспонированной свёртки

**Аналогия:** Обычная свёртка — как сжатие информации. Транспонированная свёртка — как распаковка обратно, но с учётом изученных паттернов.

**Демонстрация:** Покажите, как `ConvTranspose2d` с ядром 2×2 и шагом 2 увеличивает размерность.

#### 9.3. Объяснение skip-connections

**Аналогия:** Представьте, что вы пишете реферат. Сначала вы пишете краткий план (encoder), затем подробно раскрываете каждую часть (decoder), но постоянно сверяетесь с планом, чтобы ничего не упустить (skip-connections).

#### 9.4. Работа с масками

**Важно:** Объясните, что маски — это не обычные изображения. Они содержат индексы классов (0, 1, 2, ...) и должны обрабатываться как целочисленные данные.

```python
import torch

import cv2
import numpy as np
import os
import matplotlib.pyplot as plt

# Настройка устройства
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
print(f"Используется устройство: {device}")

# Класс Dataset
class SegmentationDataset(Dataset):
    def __init__(self, image_paths, mask_paths, transform=None):
        self.image_paths = image_paths
        self.mask_paths = mask_paths
        self.transform = transform
    
    def __len__(self):
        return len(self.image_paths)
    
    def __getitem__(self, idx):
        image = cv2.imread(self.image_paths[idx])
        image = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)
        mask = cv2.imread(self.mask_paths[idx], cv2.IMREAD_GRAYSCALE)
        
        if self.transform:
            image = self.transform(image)
            mask = self.transform(mask)
        
        mask = torch.from_numpy(mask).long()
        return image, mask

# Модель U-Net
class DoubleConv(nn.Module):
    def __init__(self, in_channels, out_channels):
        super().__init__()
        self.conv = nn.Sequential(
            nn.Conv2d(in_channels, out_channels, 3, padding=1),
            nn.BatchNorm2d(out_channels),
            nn.ReLU(inplace=True),
            nn.Conv2d(out_channels, out_channels, 3, padding=1),
            nn.BatchNorm2d(out_channels),
            nn.ReLU(inplace=True)
        )
    
    def forward(self, x):
        return self.conv(x)

class UNet(nn.Module):
    def __init__(self, in_channels=3, num_classes=3, features=[64, 128, 256, 512]):
        super().__init__()
        self.encoder = nn.ModuleList()
        self.pool = nn.MaxPool2d(2, 2)
        
        for feature in features:
            self.encoder.append(DoubleConv(in_channels, feature))
            in_channels = feature
        
        self.bottleneck = DoubleConv(features[-1], features[-1] * 2)
        
        self.upconvs = nn.ModuleList()
        self.decoders = nn.ModuleList()
        
        for feature in reversed(features):
            self.upconvs.append(nn.ConvTranspose2d(feature * 2, feature, 2, 2))
            self.decoders.append(DoubleConv(feature * 2, feature))
        
        self.final_conv = nn.Conv2d(features[0], num_classes, 1)
    
    def forward(self, x):
        skip_connections = []
        
        for encoder in self.encoder:
            x = encoder(x)
            skip_connections.append(x)
            x = self.pool(x)
        
        x = self.bottleneck(x)
        skip_connections = skip_connections[::-1]
        
        for idx in range(len(self.upconvs)):
            x = self.upconvs[idx](x)
            if x.shape != skip_connections[idx].shape:
                _, _, h, w = skip_connections[idx].shape
                _, _, xh, xw = x.shape
                x = x[:, :, (xh - h) // 2:(xh - h) // 2 + h, (xw - w) // 2:(xw - w) // 2 + w]
            x = torch.cat([skip_connections[idx], x], dim=1)
            x = self.decoders[idx](x)
        
        return self.final_conv(x)

# Функции обучения
def train_epoch(model, dataloader, criterion, optimizer, device):
    model.train()
    running_loss = 0.0
    for images, masks in dataloader:
        images, masks = images.to(device), masks.to(device)
        optimizer.zero_grad()
        outputs = model(images)
        loss = criterion(outputs, masks)
        loss.backward()
        optimizer.step()
        running_loss += loss.item() * images.size(0)
    return running_loss / len(dataloader.dataset)

def validate(model, dataloader, criterion, device, num_classes):
    model.eval()
    running_loss = 0.0
    ious = []
    with torch.no_grad():
        for images, masks in dataloader:
            images, masks = images.to(device), masks.to(device)
            outputs = model(images)
            loss = criterion(outputs, masks)
            running_loss += loss.item() * images.size(0)
            preds = outputs.argmax(dim=1)
            for cls in range(num_classes):
                pred_cls = (preds == cls)
                true_cls = (masks == cls)
                intersection = (pred_cls & true_cls).sum().item()
                union = (pred_cls | true_cls).sum().item()
                if union > 0:
                    ious.append(intersection / union)
    miou = np.mean(ious) if ious else 0
    return running_loss / len(dataloader.dataset), miou
```
