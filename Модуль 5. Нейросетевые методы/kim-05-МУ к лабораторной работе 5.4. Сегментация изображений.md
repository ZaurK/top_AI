### 2. Теоретические сведения

#### 2.1. Задачи сегментации

**Семантическая сегментация** — классификация каждого пикселя изображения по принадлежности к определённому классу.

**Инстансная сегментация** — отдельное выделение каждого объекта на изображении.

**Паноптическая сегментация** — объединение семантической и инстансной сегментации.

#### 2.2. Архитектуры для сегментации

**U-Net**:
- Состоит из **сжимающего пути** (encoder) и **расширяющего пути** (decoder);
- **Skip-connections** — передача карт признаков с encoder на decoder;
- Позволяет восстанавливать пространственную информацию.

**Структура U-Net:**
```
Encoder (сжатие):           Decoder (расширение):
Input -> Conv -> Pool ->    Up-conv -> Conv -> Skip-connection
         Conv -> Pool ->    Up-conv -> Conv -> Skip-connection
         Conv -> Pool ->    Up-conv -> Conv -> Skip-connection
         Conv -> Pool ->    Up-conv -> Conv -> Skip-connection
         Bottleneck         Output (mask)
```

**FCN (Fully Convolutional Network)**:
- Заменяет полносвязные слои на свёрточные;
- Использует транспонированную свёртку для восстановления размера;
- Применяет skip-connections для улучшения детализации.

**DeepLab**:
- Использует **Atrous Convolution** (дырчатая свёртка) для увеличения receptive field без потери разрешения;
- Применяет **ASPP (Atrous Spatial Pyramid Pooling)** для захвата контекста на разных масштабах.

#### 2.3. Метрики качества сегментации

**IoU (Intersection over Union)**:
$$
IoU = \frac{TP}{TP + FP + FN}
$$

**mIoU (mean IoU)**:
$$
mIoU = \frac{1}{N} \sum_{i=1}^{N} IoU_i
$$

**Pixel Accuracy**:
$$
PA = \frac{TP + TN}{TP + TN + FP + FN}
$$

#### 3.2. Реализация модели U-Net

```python
class DoubleConv(nn.Module):
    """Двойной свёрточный блок: Conv -> BN -> ReLU -> Conv -> BN -> ReLU"""
    def __init__(self, in_channels, out_channels):
        super(DoubleConv, self).__init__()
        self.conv = nn.Sequential(
            nn.Conv2d(in_channels, out_channels, kernel_size=3, padding=1),
            nn.BatchNorm2d(out_channels),
            nn.ReLU(inplace=True),
            nn.Conv2d(out_channels, out_channels, kernel_size=3, padding=1),
            nn.BatchNorm2d(out_channels),
            nn.ReLU(inplace=True)
        )
    
    def forward(self, x):
        return self.conv(x)

class UNet(nn.Module):
    def __init__(self, in_channels=3, num_classes=3, features=[64, 128, 256, 512]):
        super(UNet, self).__init__()
        self.encoder = nn.ModuleList()
        self.pool = nn.MaxPool2d(kernel_size=2, stride=2)
        
        # Encoder (сжатие)
        for feature in features:
            self.encoder.append(DoubleConv(in_channels, feature))
            in_channels = feature
        
        # Bottleneck
        self.bottleneck = DoubleConv(features[-1], features[-1] * 2)
        
        # Decoder (расширение)
        self.upconvs = nn.ModuleList()
        self.decoders = nn.ModuleList()
        
        for feature in reversed(features):
            self.upconvs.append(
                nn.ConvTranspose2d(feature * 2, feature, kernel_size=2, stride=2)
            )
            self.decoders.append(DoubleConv(feature * 2, feature))
        
        # Output
        self.final_conv = nn.Conv2d(features[0], num_classes, kernel_size=1)
    
    def forward(self, x):
        skip_connections = []
        
        # Encoder
        for encoder in self.encoder:
            x = encoder(x)
            skip_connections.append(x)
            x = self.pool(x)
        
        # Bottleneck
        x = self.bottleneck(x)
        
        # Decoder
        skip_connections = skip_connections[::-1]
        
        for idx in range(len(self.upconvs)):
            x = self.upconvs[idx](x)
            skip = skip_connections[idx]
            
            # Обрезка, если размеры не совпадают
            if x.shape != skip.shape:
                x = self._crop(x, skip.shape)
            
            x = torch.cat([skip, x], dim=1)
            x = self.decoders[idx](x)
        
        return self.final_conv(x)
    
    def _crop(self, x, target_shape):
        """Обрезка до целевого размера"""
        _, _, h, w = target_shape
        _, _, xh, xw = x.shape
        dh = (xh - h) // 2
        dw = (xw - w) // 2
        return x[:, :, dh:dh+h, dw:dw+w]
```

#### 3.3. Функции обучения и валидации

```python
def train_epoch(model, dataloader, criterion, optimizer, device):
    model.train()
    running_loss = 0.0
    correct = 0
    total = 0
    
    for images, masks in dataloader:
        images, masks = images.to(device), masks.to(device)
        
        optimizer.zero_grad()
        outputs = model(images)
        loss = criterion(outputs, masks)
        loss.backward()
        optimizer.step()
        
        running_loss += loss.item() * images.size(0)
        
        # Вычисление pixel accuracy
        _, preds = torch.max(outputs, 1)
        correct += (preds == masks).sum().item()
        total += masks.numel()
    
    epoch_loss = running_loss / len(dataloader.dataset)
    epoch_acc = 100. * correct / total
    return epoch_loss, epoch_acc

def validate(model, dataloader, criterion, device, num_classes):
    model.eval()
    running_loss = 0.0
    correct = 0
    total = 0
    ious = []
    
    with torch.no_grad():
        for images, masks in dataloader:
            images, masks = images.to(device), masks.to(device)
            outputs = model(images)
            loss = criterion(outputs, masks)
            
            running_loss += loss.item() * images.size(0)
            
            # Вычисление pixel accuracy
            _, preds = torch.max(outputs, 1)
            correct += (preds == masks).sum().item()
            total += masks.numel()
            
            # Вычисление IoU для каждого класса
            for cls in range(num_classes):
                pred_cls = (preds == cls)
                true_cls = (masks == cls)
                intersection = (pred_cls & true_cls).sum().item()
                union = (pred_cls | true_cls).sum().item()
                if union > 0:
                    ious.append(intersection / union)
    
    epoch_loss = running_loss / len(dataloader.dataset)
    epoch_acc = 100. * correct / total
    miou = np.mean(ious) if ious else 0
    return epoch_loss, epoch_acc, miou
```

def compute_iou(y_true, y_pred, num_classes):
    """Вычисление IoU для каждого класса"""
    ious = []
    for cls in range(num_classes):
        y_true_cls = (y_true == cls).astype(int)
        y_pred_cls = (y_pred == cls).astype(int)
        intersection = np.sum(y_true_cls * y_pred_cls)
        union = np.sum(y_true_cls) + np.sum(y_pred_cls) - intersection
        iou = intersection / (union + 1e-8)
        ious.append(iou)
    return ious

def compute_metrics(y_true, y_pred, num_classes):
    """Вычисление всех метрик"""
    ious = compute_iou(y_true, y_pred, num_classes)
    miou = np.mean(ious)
    return ious, miou

```python
# Расширенный набор аугментаций для сегментации
import torchvision.transforms.functional as TF
import random

class SegmentationTransform:
    """Класс для комплексной аугментации данных сегментации"""
    def __init__(self, image_size=(128, 128), augmentation=True):
        self.image_size = image_size
        self.augmentation = augmentation
    
    def __call__(self, image, mask):
        # Преобразование в PIL
        if isinstance(image, np.ndarray):
            image = Image.fromarray(image)
            mask = Image.fromarray(mask)
        
        # Resize
        image = TF.resize(image, self.image_size)
        mask = TF.resize(mask, self.image_size, interpolation=Image.NEAREST)
        
        # Аугментация
        if self.augmentation:
            # Случайный поворот
            if random.random() > 0.5:
                angle = random.randint(-20, 20)
                image = TF.rotate(image, angle)
                mask = TF.rotate(mask, angle, interpolation=Image.NEAREST)
            
            # Случайное горизонтальное отражение
            if random.random() > 0.5:
                image = TF.hflip(image)
                mask = TF.hflip(mask)
            
            # Случайное вертикальное отражение
            if random.random() > 0.5:
                image = TF.vflip(image)
                mask = TF.vflip(mask)
            
            # Случайное изменение яркости и контрастности
            if random.random() > 0.5:
                brightness = random.uniform(0.8, 1.2)
                contrast = random.uniform(0.8, 1.2)
                image = TF.adjust_brightness(image, brightness)
                image = TF.adjust_contrast(image, contrast)
        
        # Преобразование в тензор
        image = TF.to_tensor(image)
        mask = TF.to_tensor(mask)
        
        # Нормализация изображения
        image = TF.normalize(image, mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225])
        
        # Маска должна быть в формате long (индексы классов)
        mask = (mask * 255).long().squeeze(0)
        
        return image, mask
```
