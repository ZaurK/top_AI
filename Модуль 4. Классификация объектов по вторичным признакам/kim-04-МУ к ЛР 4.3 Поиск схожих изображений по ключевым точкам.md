## 1. ЦЕЛЬ РАБОТЫ

Целью лабораторной работы является практическое освоение методов поиска схожих изображений на основе сопоставления ключевых точек и их дескрипторов. В ходе выполнения работы студенты должны:

1. Изучить принципы работы детекторов ключевых точек (Harris, FAST, DoG и др.).
2. Освоить методы построения дескрипторов (SIFT, SURF, ORB, BRISK, A-KAZE, FREAK, LATCH).
3. Научиться сопоставлять ключевые точки между изображениями.
4. Освоить фильтрацию ложных совпадений с помощью алгоритма RANSAC.
5. Реализовать полный pipeline поиска схожих изображений.

## 2. ТЕОРЕТИЧЕСКАЯ ЧАСТЬ

### 2.1. Ключевые точки и их детекторы

**Ключевые точки** (keypoints) — это координаты точек интереса на изображении, которые обладают уникальными свойствами и устойчивостью к различным преобразованиям. Они используются для дальнейшего вычисления дескрипторов и сопоставления изображений.

#### 2.1.1. Детекторы углов

**Детектор Харриса (Harris Corner Detector)** — один из классических методов обнаружения угловых точек. Основан на анализе изменения интенсивности при сдвиге окна в различных направлениях. Фиксированный масштабный детектор Харриса показывает одни из лучших результатов среди классических методов.

**Детектор Фестнера (Förstner Corner Detector)** — использует анализ ошибок для определения угловых точек, устойчив к шуму.

**Детектор SUSAN (Smallest Univalue Segment Assimilating Nucleus)** — основан на сравнении интенсивности центрального пикселя с пикселями в его окрестности. Обеспечивает хороший баланс между точностью и эффективностью.

#### 2.1.2. Детекторы блобов

**DoG (Difference of Gaussian)** — детектор, использующий разность гауссиан для поиска блобов на разных масштабах. Является основой алгоритма SIFT. DoG показывает высокую производительность в большинстве видео, хотя имеет наименьшую эффективность среди некоторых методов.

### 2.2. Дескрипторы ключевых точек

**Дескриптор** — это вектор признаков, вычисляемый в окрестности ключевой точки, который позволяет сравнивать ключевые точки между изображениями и определять их схожесть.

#### 2.2.1. Группа SIFT/SURF (плавающие дескрипторы)

**SIFT (Scale-Invariant Feature Transform)** — один из первых и самых известных алгоритмов. Дескрипторы SIFT инвариантны относительно масштабирования, изменения ориентации и освещенности. В основе лежит вычисление гистограммы ориентированных градиентов в окрестности особой точки. SIFT обеспечивает высокую точность сопоставления, но требует значительных вычислительных ресурсов.

**SURF (Speeded-Up Robust Features)** — ускоренная версия SIFT, использующая матрицу Гессе и интегральные изображения для повышения скорости. Обеспечивает хорошую производительность при высокой скорости обработки.

#### 2.2.2. Бинарные дескрипторы

Бинарные дескрипторы представляют собой векторы из 0 и 1, что обеспечивает высокую скорость вычислений и сравнения с использованием расстояния Хэмминга.

**ORB (Oriented FAST and Rotated BRIEF)** — комбинирует детектор FAST и дескриптор BRIEF с добавлением инвариантности к повороту. Является самым быстрым из рассмотренных алгоритмов. Детектирует наибольшее количество ключевых точек среди бинарных методов. В реализации OpenCV использует 32-байтовые дескрипторы.

**BRISK (Binary Robust Invariant Scalable Keypoints)** — бинарный дескриптор, устойчивый к масштабированию и повороту. Использует 64-байтовые дескрипторы и расстояние Хэмминга для сравнения.

**A-KAZE (Accelerated-KAZE)** — ускоренная версия KAZE, использующая нелинейную диффузию для построения масштабного пространства. Обеспечивает высокую производительность при фотометрических преобразованиях. Использует 64-байтовые дескрипторы.

**FREAK (Fast Retina Keypoint)** — бинарный дескриптор, вдохновленный биологией человеческого глаза. Использует детектор Харриса и 64-байтовые дескрипторы.

**LATCH (Learned Arrangements of Three Patch Codes)** — бинарный дескриптор, использующий детектор FAST и 32-байтовые дескрипторы.

### 2.3. Сопоставление дескрипторов

Для сопоставления дескрипторов между изображениями используются различные методы:

- **Brute-force сопоставитель** — сопоставляет дескриптор ключевой точки одного изображения со всеми дескрипторами точек другого изображения, используя некоторую функцию расстояния.
- **FLANN (Fast Library for Approximate Nearest Neighbors)** — использует приближенные методы поиска для ускорения сопоставления на больших наборах данных.

Для плавающих дескрипторов (SIFT, SURF) используется **евклидово расстояние**. Для бинарных дескрипторов (ORB, BRISK, FREAK, LATCH) используется **расстояние Хэмминга**.

### 2.4. Фильтрация ложных совпадений (RANSAC)

**RANSAC (RANdom SAmple Consensus)** — алгоритм, предложенный Фишлером и Боллесом в 1981 году, ставший наиболее широко используемым методом для фильтрации выбросов и оценки параметров моделей.

В контексте сопоставления изображений RANSAC используется для определения правильных совпадений между ключевыми точками двух изображений и помогает избавиться от ложных совпадений, вызванных шумом или искажениями.

**Принцип работы:**
1. Случайно выбирается минимальный набор сопоставленных точек (например, 4 пары для оценки гомографии).
2. Вычисляется модель преобразования.
3. Проверяется, сколько других сопоставлений соответствует этой модели в пределах порога ошибки.
4. Процесс повторяется множество итераций.
5. Выбирается модель с наибольшим количеством inliers (правильных совпадений).

RANSAC вычисляет гомографию между ключевыми точками для определения правильных совпадений.

### 2.5. Области применения

Сопоставление ключевых точек позволяет решать широкий круг задач компьютерного зрения:

- **Обнаружение объекта в сцене** — поиск известного объекта на изображении.
- **Классификация изображений** — сравнение с эталонными изображениями.
- **Оценка геометрических преобразований** — определение поворота, масштаба и сдвига между кадрами.
- **Совмещение и склейка изображений (панорамирование)** — создание панорамных изображений.
- **Стереозрение** — сопоставление точек в стереопаре для оценки глубины.
- **Восстановление рельефа** — 3D-реконструкция по нескольким изображениям.
- **3D-реинжиниринг** — восстановление 3D-моделей объектов.
- **Анализ сцен** — понимание структуры и содержания сцены.

### 3.2. Структура лабораторной работы

#### Задание 1. Обнаружение и визуализация ключевых точек

Реализовать детектирование ключевых точек на изображении с использованием различных детекторов.

**Ход выполнения:**
1. Загрузить тестовое изображение.
2. Применить детекторы: Harris, FAST, SIFT (DoG), SURF.
3. Визуализировать обнаруженные ключевые точки с помощью `cv2.drawKeypoints()`.
4. Сравнить количество и распределение ключевых точек для каждого детектора.

#### Задание 2. Построение и сравнение дескрипторов

Реализовать вычисление дескрипторов различными методами и сравнить их характеристики.

**Ход выполнения:**
1. Для одного изображения вычислить дескрипторы с помощью SIFT, SURF, ORB, BRISK, A-KAZE.
2. Проанализировать размерность дескрипторов и время вычисления.
3. Сравнить инвариантность дескрипторов к масштабированию и повороту.

#### Задание 3. Сопоставление ключевых точек между двумя изображениями

Реализовать сопоставление ключевых точек между эталонным и тестовым изображениями.

**Ход выполнения:**
1. Загрузить два изображения (например, объект и сцена с этим объектом).
2. Обнаружить ключевые точки и вычислить дескрипторы для обоих изображений.
3. Выполнить сопоставление дескрипторов с использованием brute-force сопоставителя.
4. Визуализировать результаты сопоставления.

#### Задание 4. Фильтрация ложных совпадений с помощью RANSAC

Реализовать фильтрацию ложных совпадений и оценку геометрического преобразования.

**Ход выполнения:**
1. На основе сопоставленных точек оценить гомографию с использованием RANSAC.
2. Отфильтровать выбросы и оставить только inliers.
3. Визуализировать результаты до и после фильтрации.
4. Оценить точность найденного преобразования.

#### Задание 5. Поиск схожих изображений в коллекции

Реализовать поиск изображений, схожих с запросом, в базе изображений.

**Ход выполнения:**
1. Создать базу из 10–20 изображений.
2. Для каждого изображения базы вычислить дескрипторы.
3. Для изображения-запроса вычислить дескрипторы и выполнить сопоставление с каждым изображением базы.
4. Ранжировать изображения по количеству правильных совпадений (inliers после RANSAC).
5. Вывести топ-5 наиболее схожих изображений.
