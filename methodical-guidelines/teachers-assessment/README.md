# Методические указания преподавателям по оцениванию

Результаты обучения рекомендуется оценивать с помощью ФОС по системе РИТМ.
ФОС включает в себя:
> 1) Лабораторные работы (обязательные виды работ) для текущего контроля;
> 2) Проектную работу (дополнительная работа);
> 3) Банк вопросов для тестов семестрового контроля и экзамена.

## Текущий контроль
Текущий контроль проводится по итогам защиты выполненных лабораторных работ. Каждая лабораторная работа оценивается 0–100 баллов с порогом 65 баллов. При превышении этого порога баллы накапливаются.
Рекомендации по ценке лабораторных работ приводятся в методических указаниях для преподавателя по соответствующей лабораторной работе.

Для контроля равномерности работы обучающихся в течение семестра вводятся аттестационные недели — 7-я и 12-я. Для каждой аттестации преподавателем назначается пороговый балл. Пороги с распределением баллов по отдельным видам работ оформляются в виде технологической карты.

## Дополнительные баллы

Кроме обязательных видов работ, обучающиеся могут выполнять дополнительные работы по выбору: проектная деятельность, участие в олимпиадах по ИИ, исследовательская работа с представлением рефератов и выступлением с докладами на конференциях, решение заданий повышенной сложности, выполнение комплексных усложненных лабораторных работ и т.п.

Особенностью дополнительных работ по выбору является то, что за их выполнение обучающийся может получить не более 20 баллов (**Nд**) по шкале промежуточной аттестации.

## Семестровый контроль

По итогам работы обучающегося в семестре по системе РИТМ оценка по дисциплине может быть выставлена автоматически, но только после прохождения специальной контрольной акции — семестрового контроля.

К семестровому контролю допускаются студенты, не имеющие задолженностей по обязательным видам работ.

Семестровый контроль проводится согласно расписанию занятий и в форме тестирования, охватывающего все темы дисциплины, и оценивается в диапазоне 10–20 (**Ncк**).

При выполнении всех обязательных работ (до начала сессии) накопленные баллы (**Nс**) для промежуточной аттестации определяются по формуле:

**Nс = Nт + Ncк + Nд**

Оценка выставляется автоматически по системе РИТМ:  
- **60** — порог тройки,  
- **75** — хорошо,  
- **90** — отлично.

## Экзамен

Если студент не прошел семестровый контроль, или студент хочет повысить оценку, промежуточная аттестация проводится в форме экзамена. Экзамен проводится в виде компьютерного тестирования с на ⅓ большим числом вопросов по сравнению с тестом семестрового контроля. Экзамен оценивается от 0 до 30 баллов с порогом 15 баллов.

Итоговый балл в этом случае рассчитывается следующим образом:

**Nс = Nт + Nд + Nэ**

Пороги оценок:  
- **60** — порог тройки,  
- **75** — хорошо,  
- **90** — отлично.
