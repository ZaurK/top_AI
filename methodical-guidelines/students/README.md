# МЕТОДИЧЕСКИЕ РЕКОМЕНДАЦИИ ПО ИЗУЧЕНИЮ ДИСЦИПЛИНЫ

Дисциплина включает обязательные для выполнения части:

- Часть 1. Теоретические разделы;
- Часть 2. Компьютерный практикум;
- Часть 3. Итоговая проверка освоения всех разделов дисциплины.

Дополнительная работа заключается в проектной деятельности, выполнении лабораторных заданий или кейсов повышенной сложности.

Дисциплина изучается с поддержкой электронного курса образовательного портала вуза.

## Теоретические разделы

В данной части осваиваются фундаментальные понятия, подходы и методы решения задач компьютерного зрения.

Теоретические разделы дисциплины изучаются на лекциях и (или) самостоятельно с помощью рекомендованных информационных ресурсов.

Все пройденные элементы каждой темы теоретических разделов автоматически учитываются на ЭК. Текущий уровень освоения материалов проверяется при защите лабораторных работ. Итоговый контроль проводится в форме тестирования по пройденным темам модулей.

## Компьютерный практикум

Компьютерный практикум посвящен освоению технологий для автоматизации решения задач компьютерного зрения.

Каждая лабораторная работа содержит несколько заданий с методическими указаниями в прикрепленных файлах.

Выполненные задания в виде файлов документов и кода прикрепляются на электронном курсе с помощью инструмента «Добавить ответ на задание». Все прикрепленные файлы могут послужить в роли портфолио обучающегося для работодателя.

Каждая лабораторная работа оценивается по 100-балльной шкале. Критерии оценивания приводятся в методических указаниях к лабораторным работам.

Для стимуляции ритмичной работы в течение семестра вводятся аттестационные недели – 7-я и 12-я и в конце семестра. Для каждой аттестации преподавателем назначается пороговый балл. Рекомендованные пороговые баллы даны в табл. 1.

## Итоговая проверка освоения всех разделов дисциплины

Итоговая проверка освоения дисциплины проводится в виде семестрового контроля и / или экзамена в форме компьютерного тестирования по всем модулям.

Семестровый контроль обычно проводится на заключительном аудиторном занятии семестра по дисциплине с оценкой до 20 баллов и порогом в 10 баллов. К нему допускаются студенты, не имеющие задолженностей по компьютерному практикуму.

При успешном прохождении семестрового контроля оценка выставляется автоматически.

Для непрошедших семестровый контроль необходимо сдавать экзамен. Экзамен проводится согласно расписанию сессии и оценивается автоматически в диапазоне 0..30 с порогом в 15 баллов.

Экзамен также могут сдавать студенты, желающие повысить автоматическую оценку после семестрового контроля. На экзамене решаются большее в 1,5 раза количество тестов по всем темам дисциплины. Понижение оценки экзаменом относительно оценки после семестрового контроля не предусмотрено.

## Дополнительные баллы

Кроме обязательных видов работ предусмотрены дополнительные работы: проектная деятельность, участие в олимпиадах по ИИ, исследовательская работа с представлением рефератов и выступлением с докладами на конференциях, решение заданий повышенной сложности, выполнение комплексных усложненных лабораторных работ и т.п.

С требованиями к проектам и необходимые ресурсы приводятся в методических указаниях по проектной деятельности. Проект защищается очно.

Особенностью дополнительных работ по выбору является то, что за их выполнение обучающийся может получить не более 20 баллов (Nд) по шкале промежуточной аттестации.

## Общая оценка дисциплины

### Семестровый контроль

По итогам работы обучающегося в семестре по системе РИТМ оценка по дисциплине может быть выставлена автоматически, но только после прохождения специальной контрольной акции – семестрового контроля.

К семестровому контролю допускаются студенты, не имеющие задолженностей по обязательным видам работ.

Семестровый контроль проводится согласно расписанию занятий и в форме тестирования, охватывающего все темы дисциплины, и оценивается в диапазоне 10–20 (Ncк).

При выполнении всех обязательных работ (до начала сессии) накопленные баллы (Nс) для промежуточной аттестации определяются по формуле:

**Nс = Nт + Ncк + Nд**

Оценка выставляется автоматически по системе РИТМ: 60 – порог тройки, 75 – хорошо, 90 – отлично.

### Экзамен

Если студент не прошел семестровый контроль, или студент хочет повысить оценку, промежуточная аттестация проводится в форме экзамена. Экзамен проводится в виде компьютерного тестирования с на ⅓ большим числом вопросов по сравнению с тестом семестрового контроля. Экзамен оценивается от 0 до 30 баллов с порогом 15 баллов.

Итоговый балл в этом случае рассчитывается следующим образом:

**Nс = Nт + Nд + Nэ**

Пороги оценок: 60 – порог тройки, 75 – хорошо, 90 – отлично.

Если полученный на экзамене балл не повышает оценку, то действует оценка, полученная по первой формуле, т.е. с учетом семестрового контроля.

## Взаимодействие при изучении дисциплины

Для взаимодействия при изучении дисциплины на электронном курсе предусмотрены два ресурса:

- **Объявления** – содержат все объявления преподавателей для студентов этого электронного курса. При размещении преподавателем объявления оно автоматически рассылается на электронную почту каждому студенту, которую указал студент при настройке своего профиля на образовательном портале.

- **Форум** – позволяет любому участнику электронного курса формировать свои новые темы, инициируя обсуждения внутри данных тем. Это позволяет взаимодействовать как с преподавателем, так и студентам между собой.
